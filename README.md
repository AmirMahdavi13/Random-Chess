# شطرنج کلاسیک و Random Chess

بازی شطرنج گرافیکی با پایتون (pygame) — رابط کاربری فارسی.

## اجرا

```bat
start.bat
```

یا دستی:

```bat
pip install -r requirements.txt
python main.py
```

## امکانات

- **شطرنج کلاسیک** با قوانین کامل: قلعه، آن‌پاسان، ارتقای پیاده، کیش/مات/پات و مساوی به‌دلیل کمبود مهره.
- **Random Chess**: در هر بازیِ جدید، مهره‌های ردیف آخر (به‌جز شاه و پیاده‌ها) الگوی حرکتی تصادفی از مهره‌های دیگر می‌گیرند — مثلاً اسب مثل رخ حرکت می‌کند. الگوی هر مهره با یک نشانِ کوچک روی خود مهره و جدولی در نوار کناری مشخص می‌شود. تخصیص بین دو ارتش قرینه است تا بازی منصفانه بماند (قلعه هم در این حالت غیرفعال است چون معنایش دیگر حفظ نمی‌شود).
- **حریف کامپیوتری** با سه سطح: آسان (طمع‌کارانه با خطای عمدی)، متوسط (عمق ۲) و سخت (عمق ۴ با جست‌وجوی آلفا-بتا، تعمیق تدریجی و جست‌وجوی آرامش).
- **بازی دو نفره** روی یک صفحه.
- **زمان بازی**: ۱۰ دقیقه، ۱۵ دقیقه یا بدون محدودیت برای هر بازیکن؛ زمان با اولین حرکت شروع می‌شود و زمان فکرِ کامپیوتر هم از ساعتش کم می‌شود.
- انتخاب رنگ (سفید/سیاه) هنگام بازی با کامپیوتر؛ صفحه به‌طور خودکار برای سیاه برعکس می‌شود.
- **انیمیشن حرکت مهره‌ها**: مهره‌ها به‌نرمی بین مربع مبدا و مقصد می‌لغزند (شامل حرکت رخ هنگام قلعه)؛ حین انیمیشن ورودی موقتاً قفل است.
- **برگشت حرکت**: در بازی دو نفره یک نیم‌حرکت و در بازی با کامپیوتر حرکتِ شما + پاسخ ربات با هم برمی‌گردند (ارتقا هم درست بازگردانی می‌شود). حتی بعد از پایان بازی هم می‌شود برگشت؛ زمان ساعت‌ها برگردانده نمی‌شود.

## ساختار

| فایل | توضیح |
|---|---|
| `engine.py` | موتور قوانین شطرنج با الگوی حرکت قابل‌تعویض برای هر مهره |
| `ai.py` | ربات (نگاتیو-مکس + هرس آلفا-بتا + تعمیق تدریجی + جست‌وجوی آرامش) |
| `ui.py` | رابط گرافیکی pygame با متن فارسی (arabic-reshaper + python-bidi) |
| `main.py` | نقطهٔ ورود |

## تست‌ها

```bat
python test_engine.py   :: perft روی ۵ موقعیت استاندارد + قوانین + حالت Random
python test_ai.py       :: یافتن مات، قانونی بودن حرکات، سرعت
python test_ui.py       :: رندر اسکرین‌شات در shots/ و یک بازی کامل بی‌سر
```

تست perft با مقادیر مرجع (شامل Kiwipete و موقعیت‌های آن‌پاسان/ارتقا) مطابقت کامل دارد.
